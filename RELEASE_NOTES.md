# BlendSDK v5.57.0 — Release Notes

**Released**: 2026-09-16

We are excited to announce the release of BlendSDK version 5.57.0. This update brings several enhancements that improve the overall functionality and usability of the SDK, helping users create better applications with increased efficiency and reliability. The updates are mainly focused on enhancing documentation, streamlining processes, and refining existing features to ensure a smoother development experience.

Here are the key highlights of what’s new in this release:

**Enhanced Documentation and Usability**  
To make it easier for new users and developers to navigate the SDK, we have updated our documentation significantly. Key additions include clearer guidance on installing skills and working with the AI training features. This change not only aids developers in using our SDK but also reduces onboarding time for new team members.

**Skill Installer and Installation Commands**  
Version 5.57.0 introduces a simplified skill installer along with installation commands. This allows users to set up and start using skills more quickly, removing unnecessary steps from the setup process.

**Updated API Client and Code Generation**  
The API client has been refined to improve its robustness and ease of use. The updates ensure that users can generate API clients more reliably, allowing for fewer errors and a better alignment with current practices in API usage.

**Security and Performance Improvements**  
With this release, we have focused on enhancing security measures within the SDK, particularly around authentication processes and session management. These updates provide users with peace of mind while developing sensitive applications.

**Refreshed Skill References**  
We have generated versionless references for AI training and skills, which keep information straightforward and current without version complications. This ensures that developers always have access to the most relevant information, contributing to a smoother development experience.

Overall, BlendSDK version 5.57.0 is centered on improving the user experience by making our tools easier to use, safer, and more efficient. We are confident these changes will provide significant benefits as you continue to leverage our SDK in your projects.
