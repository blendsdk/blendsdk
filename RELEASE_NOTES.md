# BlendSDK v5.65.0 — Release Notes

**Released**: 2026-09-27

We are excited to announce the release of BlendSDK version 5.65.0! This latest update brings a range of enhancements and improvements across various packages that will benefit our users, enhance security, and streamline development processes.

### Summary of Key Changes

1. **Enhanced Security Measures**: Several updates across the SDK packages focus on improving security, particularly around user authorization and session management. This includes stricter checks and hardening measures to safeguard user sessions, which will help in maintaining the integrity of user authentication processes.

2. **Better Documentation**: As part of our commitment to user support, we have improved our documentation to ensure that developers can easily navigate and understand the SDK’s features. This includes clear guidelines on interactive elements and enhanced explanations of processes.

3. **New Features and Improved Functionality**: We’ve introduced new features, such as authorization hooks and route guard components. These additions will make it easier for developers to implement security checks and manage user access more efficiently.

4. **Integration and Compatibility**: The SDK now offers better integration capabilities with various services, allowing users to connect seamlessly with different technology stacks. Additionally, enhancements to our client and tooling will minimize setup time for new projects.

5. **Performance Improvements**: Consistent updates have led to performance optimizations across multiple packages, which means faster load times and more efficient use of system resources during operation.

These changes not only improve the SDK's overall functionality but also provide a more reliable and secure framework for developers. We believe these updates will enhance the user experience, allowing for more robust applications and a smoother development process. Thank you for your continued support as we strive to provide the best tools for your development needs!
