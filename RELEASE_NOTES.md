# BlendSDK v5.68.0 — Release Notes

**Released**: 2026-10-29

We are excited to announce the release of BlendSDK version 5.68.0! This update includes a variety of improvements that enhance the functionality, security, and usability of our software development kit. 

In this version, we have made key updates across several packages that will provide developers with a smoother experience and ensure that projects utilizing our SDK remain robust and secure. The updates also improve the overall documentation, making it easier for users to access the information they need.

Here are some key highlights from this release:

### API Client Enhancements
The API Client has had its dependencies updated and improved documentation added, providing clearer guidance on using the SDK. Additionally, a new typed HTTP client runtime has been introduced, further simplifying development processes.

### Authorization Improvements
Enhancements to the authorization package ensure that user claims are processed more securely and efficiently. This includes better handling of authorization examples and improved testing for validation scenarios.

### BlendScript Refinements
There have been updates to BlendScript for more accurate diagnostics and better content generation, ensuring that developers have access to the right tools for their projects.

### Documentation Enhancements
We have refreshed our documentation across several components of the SDK, targeting improved clarity and ease of understanding. This will be invaluable for both new and existing users.

### General Security Updates
Security has been a focus in this release. Implementation of new hardening measures ensures that user data remains safe while interacting with the SDK.

### Miscellaneous Updates
We have also worked on performance improvements, streamlined installation commands, and made several packaging updates across various components, aiming for a more cohesive and efficient development experience.

These improvements reflect our commitment to continually refine and enhance the BlendSDK, ensuring our users have the best tools available for developing their applications. We encourage all users to update to version 5.68.0 to take advantage of these enhancements!
