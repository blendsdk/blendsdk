Quick Start ​

Welcome to the BlendSDK Quick Start guide! In this walkthrough, you will build a REST API using BlendSDK, complete with CRUD endpoints and PostgreSQL integration. Let's get started and have a comprehensive API up and running in under 10 minutes.

Project Creation ​

First, create a new project folder and initialize a Node.js project:

bash
mkdir my-blend-app && cd my-blend-app
npm init -y

Next, install the necessary packages:

bash
npm install blendsdk/webafx blendsdk/postgresql

Application Setup with webafx ​

Create a new file called app.ts. This file will set up your main application using webafx.

typescript
import { WebApplication, BaseController } from 'blendsdk/webafx';
import { UserController } from './userController';

const app = new WebApplication({
  PORT: 3000,
});

app.registerController('/api/users', UserController);

app.start().then(() => {
  console.log('Server is running on http://localhost:3000');
});

User Controller with CRUD Endpoints ​

Create a file named userController.ts. This file will define a CRUD controller for user operations using webafx.

typescript
import { BaseController } from 'blendsdk/webafx';
import { PostgreSQLDatabase } from 'blendsdk/postgresql';
import { Request, Response } from 'express';
import { dbConfig } from './dbConfig';

const db = new PostgreSQLDatabase(dbConfig);

export class UserController extends BaseController {
  routes() {
    return [
      this.route().get('/').handle(this.listUsers),
      this.route().get('/:id').handle(this.getUserById),
      this.route().post('/').handle(this.createUser),
    ];
  }

  async listUsers(req: Request, res: Response) {
    const users = await db.executeQuery('SELECT * FROM users');
    this.ok(res, users.records);
  }

  async getUserById(req: Request, res: Response) {
    const { id } = req.params;
    const user = await db.executeQuery('SELECT * FROM users WHERE id = :id', { id });
    this.ok(res, user.records[0] || {});
  }

  async createUser(req: Request, res: Response) {
    const { name, email } = req.body;
    const newUser = await db
      .insert('users')
      .values({ name, email })
      .returning('*')
      .executeReturnSingle();
    this.created(res, newUser);
  }
}

Database Connection with PostgreSQL ​

Create a dbConfig.ts file to configure your PostgreSQL connection:

typescript
export const dbConfig = {
  host: 'localhost',
  port: 5432,
  database: 'myappdb',
  user: 'dbuser',
  pass: 'dbpass',
};

In your PostgreSQL server, execute the following SQL to create the users table:

sql
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  name VARCHAR(100),
  email VARCHAR(100) UNIQUE
);

Running and Testing the Application ​

Run your application:

bash
ts-node app.ts

Test the API using curl commands:

  • List Users: curl http://localhost:3000/api/users
  • Get User by ID: curl http://localhost:3000/api/users/&lt;ID&gt;
  • Create a User:
bash
curl -X POST http://localhost:3000/api/users -H "Content-Type: application/json" -d '{"name": "John Doe", "email": "john@example.com"}'

What You've Built ​

Congratulations! You've just built a REST API using BlendSDK with endpoints to list, retrieve, and create users. This setup includes a robust integration with PostgreSQL, leveraging BlendSDK's powerful framework for type-safe and efficient application development.
