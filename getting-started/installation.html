Installation ​

Welcome to BlendSDK! This guide will help you set up the BlendSDK environment in your project. BlendSDK employs a flexible architecture, allowing you to tailor installations according to your specific use cases.

Prerequisites ​

Ensure your development environment meets the following criteria:

  • Node.js version 22.0.0 or higher

Step 1: Install BlendSDK ​

To get started with BlendSDK, you first need to install the core package.

bash
npm install blendsdk

Single-Package Distribution Model ​

BlendSDK employs a single-package distribution approach, which means all submodules are accessible through the blendsdk package. You can import components using the blendsdk/* subpath. This not only simplifies dependency management but also ensures a consistent versioning across modules.

typescript
import { query } from 'blendsdk/expression';

Step 2: Install Peer Dependencies ​

Depending on your use case, you might need to install specific peer dependencies. Here’s how you can install them for different scenarios:

Web Server with WebAFX ​

For web applications:

bash
npm install express cookie-parser cors helmet

Logging with WebAFX-Pino ​

For logging functionalities:

bash
npm install pino pino-http pino-pretty

Caching with WebAFX-Cache ​

For caching and real-time messaging:

bash
npm install ioredis

Email with WebAFX-Mailer ​

For sending emails:

bash
npm install nodemailer

Authentication with WebAFX-Auth ​

For authentication:

bash
npm install jose

PostgreSQL Database ​

For PostgreSQL database interactions:

bash
npm install pg yesql postgres-array

React Applications ​

For React integration:

bash
npm install react react-dom react-router

Step 3: Configure TypeScript ​

BlendSDK is built with TypeScript and works best when your project is configured in strict mode. Ensure your tsconfig.json reflects the following settings:

json
{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "esModuleInterop": true,
    "forceConsistentCasingInFileNames": true
  }
}

Step 4: Update package.json ​

To correctly handle ES modules, set your project’s package.json to specify the ESM module type:

json
{
  "type": "module",
  "dependencies": {
    "blendsdk": "^5.42.0"
  }
}

Step 5: Verify the Installation ​

To ensure everything is set up correctly, create a simple verification script.

typescript
import { formatString } from 'blendsdk/stdlib';

function testBlendSDK() {
  const message = formatString("Hello, ${name|Visitor}!", { name: "BlendSDK User" });
  console.log(message);  // Expected output: "Hello, BlendSDK User!"
}

testBlendSDK();

Run the above script using ts-node to verify that BlendSDK functions are available and working as expected.
