AI Agent Skill ​

blendsdk ships an Agent Skill — a folder with a SKILL.md and references — that teaches coding agents how to use the SDK. The skill uses public subpath imports and the real APIs, so the code an agent writes compiles against the installed package.

Install ​

The skill ships inside the blendsdk package. Install or update it into your agents with one command:

bash
npx -y blendsdk@latest skill install

The installer scans the agent skill directories on your machine and asks which to install into. For non-interactive or scripted use:

bash
npx -y blendsdk@latest skill install --all                 # every detected client
npx -y blendsdk@latest skill install --target ~/.config/opencode/skills
npx -y blendsdk@latest skill install --project             # the current project
npx -y blendsdk@latest skill install --link                # symlink to a source tree

Or via curl:

bash
curl -fsSL https://cdn.jsdelivr.net/npm/blendsdk@latest/install-skill.sh | bash

blendsdk skill status shows the installed version and blendsdk skill uninstall removes it. Pin a version with npx -y blendsdk@5.55.0 skill install.

Manual install ​

If you prefer to place the folder yourself:

bash
npm install blendsdk
mkdir -p .agents/skills
cp -R node_modules/blendsdk/skills/blendsdk .agents/skills/blendsdk

Where agents look ​

AgentProject pathsGlobal paths
OpenCode.opencode/skills/, .agents/skills/~/.config/opencode/skills/, ~/.agents/skills/
Claude Code.claude/skills/~/.claude/skills/
Codex.codex/skills/, .agents/skills/~/.codex/skills/, ~/.agents/skills/

The installer writes to these paths. A single .agents/skills/blendsdk directory serves OpenCode and Codex; the client-specific paths cover clients that only read their own directory.

Use ​

Once installed, the agent discovers the skill automatically and loads it when a task mentions BlendSDK. No configuration is required.

  • OpenCode lists the skill and loads it on demand.
  • Codex can invoke it implicitly from the description, or explicitly with $blendsdk or /skills.
  • Claude Code invokes it implicitly from the description.

Update ​

Re-run the installer to update an installed skill:

bash
npx -y blendsdk@latest skill install

The installer replaces the installed blendsdk skill directory. With --link, the installed skill tracks the source tree automatically.

Notes ​

  • The skill replaces the retired blendsdk-mcp documentation server. Existing MCP installs keep working until you remove them.
  • The skill is validated against the Agent Skills standard in CI, so its format stays compatible with every client that follows the standard.
