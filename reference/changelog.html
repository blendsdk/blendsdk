BlendSDK v5.66.0 — Release Notes ​

Released: 2026-10-01

We are excited to announce the release of BlendSDK version 5.66.0. This update brings a range of improvements and refinements to enhance the overall user experience and ensure better performance across several packages. Our goal with this release is to deliver a more secure, reliable, and user-friendly experience, making it easier for teams to integrate and utilize the SDK effectively.

Key Highlights:

1. Enhanced Security Measures
This release includes significant updates to the authentication processes, improving security for user sessions and data. New mechanisms have been added to protect against unauthorized access and to reinforce our commitment to safeguarding user information.

2. Improved Documentation
We've dedicated time to enhance our documentation, ensuring users have clear, concise, and updated information readily available. This includes better examples and guides, which will help users navigate and implement the SDK more easily.

3. Performance Optimizations
Various internal improvements have been made to increase the efficiency of the SDK. These changes are designed to improve response times and resource utilization, resulting in a smoother experience for users.

4. New Features and Enhancements
New functionalities have been implemented across several packages, which enable users to leverage advanced capabilities without complication. This includes enhancements in the authorization workflows and support for more integration options.

5. Bug Fixes and Stability Improvements
We have addressed several bugs reported by users, leading to a more stable and reliable SDK. These fixes will help users minimize disruptions and focus on their core tasks.

Overall, BlendSDK version 5.66.0 is a step forward in our ongoing effort to provide a robust and user-centric software development kit. We encourage stakeholders to take advantage of these improvements to drive better outcomes in their projects. Thank you for your continued support!
