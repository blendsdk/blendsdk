Peer Dependencies ​

BlendSDK uses optional peer dependencies. Install only what you need.

By Package ​

If you use...Install these peer deps
blendsdk/webafxexpress, cookie-parser, cors, helmet
blendsdk/webafx-pinopino, pino-http, pino-pretty
blendsdk/webafx-cacheioredis
blendsdk/webafx-mailernodemailer
blendsdk/webafx-mailer-azure@azure/msal-node
blendsdk/webafx-authjose
blendsdk/postgresqlpg, yesql, postgres-array
blendsdk/reactreact, react-dom, react-router
