Introduction ​

In this guide, you will learn how to implement authentication in a WebAFX application using BlendSDK's webafx-auth package. We will cover topics such as JWT validation, OAuth2 introspection, OIDC discovery, multi-tenant authentication routing, the authorization code flow with PKCE, and cookie-based session management. By the end of this tutorial, you will have a comprehensive understanding of how to secure a web application using these mechanisms.

Prerequisites ​

Before you begin, ensure you have the following:

  • A working knowledge of TypeScript
  • An environment set up with Node.js and npm
  • Basic understanding of authentication concepts
  • BlendSDK installation
  • A configured WebAFX application

Setting Up the Environment ​

First, you need to install the BlendSDK authentication package:

bash
npm install blendsdk/webafx-auth

or

bash
yarn add blendsdk/webafx-auth

JWT Validation with JwtAuthProvider ​

The first step in securing your application is to set up a basic JWT validation mechanism. Here's how to configure the JwtAuthProvider to validate tokens against a hardcoded secret.

typescript
import { JwtAuthProvider } from 'blendsdk/webafx-auth';
import express from 'express';

// Initialize the Express application
const app = express();

// Setup JwtAuthProvider
const jwtProvider = new JwtAuthProvider({
    secret: 'my-secret-key',
    algorithms: ['HS256'],
    issuer: 'https://api.example.com',
    audience: 'my-client-id',
});

// Middleware to validate JWT
app.use(async (req, res, next) => {
    const token = req.headers['authorization']?.split(' ')[1];
    if (!token) return res.status(401).send('Unauthorized');

    try {
        const authResult = await jwtProvider.validate(token);
        if (!authResult) return res.status(401).send('Unauthorized');

        // Attach user information to the request
        req.user = authResult;
        next();
    } catch (error) {
        return res.status(500).json({ error: 'Internal Server Error' });
    }
});

app.get('/protected', (req, res) => {
    res.send(`Hello ${req.user.sub}`);
});

app.listen(3000, () => {
    console.log('Server running on http://localhost:3000');
});

Multi-Tenant Authentication ​

In scenarios where you support multi-tenant authentication, the TenantAuthProvider allows dynamic configurations per tenant. This requires configuring an OIDC provider that adjusts to the tenant's domain.

typescript
import { OidcAuthProvider } from 'blendsdk/webafx-auth';
import express from 'express';

// Initialize the Express application
const app = express();

// Setup OIDC provider for multi-tenant
const provider = new OidcAuthProvider({
    serviceName: 'multi-tenant',
    configFactory: async (req) => {
        const tenantId = req.headers['x-tenant-id']; // Extract tenant ID

        return {
            issuerUrl: `https://auth.${tenantId}.example.com`,
            clientId: `${tenantId}-client`,
            clientSecret: `${tenantId}-secret`,
            redirectUri: `https://app.${tenantId}.example.com/callback`,
        };
    },
});

// Middleware to authenticate requests for multiple tenants
app.use(async (req, res, next) => {
    try {
        const result = await provider.authenticate(req);
        if (!result) return res.status(401).send('Unauthorized');

        req.user = result;
        next();
    } catch (error) {
        return res.status(401).json({ error: 'Unauthorized' });
    }
});

app.get('/protected', (req, res) => {
    res.send(`Hello ${req.user.sub}`);
});

app.listen(3000, () => {
    console.log('Server running on http://localhost:3000');
});

OIDC Authorization Code Flow with PKCE ​

To implement the OIDC flow with PKCE in your application, first set up the login and callback endpoints. This flow allows secure authentication and session management.

Building the Authorization URL ​

typescript
import express from 'express';
import { OidcAuthProvider } from 'blendsdk/webafx-auth';

const app = express();

const provider = new OidcAuthProvider({
    issuerUrl: 'https://auth.example.com',
    clientId: 'client-id',
    clientSecret: 'client-secret',
    redirectUri: 'https://yourapp.com/callback',
});

// Endpoint to trigger login
app.get('/auth/login', async (req, res) => {
    try {
        // Build the authorization URL
        const authUrlResult = await provider.buildAuthorizationUrl();
        res.redirect(authUrlResult.url);
    } catch (error) {
        console.error('Error building auth URL:', error);
        res.status(500).send('Internal Server Error');
    }
});

Handling the Callback ​

typescript
// Callback endpoint
app.get('/callback', async (req, res) => {
    try {
        const tokens = await provider.exchangeCode({
            codeVerifier: 'verifier-from-client',
            callbackUrl: 'https://yourapp.com/callback?code=' + req.query.code,
        });

        // Store session secure cookies
        res.cookie('session_id', tokens.accessToken, {
            httpOnly: true,
            secure: true,
        });

        res.send('Logged in successfully');
    } catch (error) {
        console.error('Error during token exchange:', error);
        res.status(401).send('Unauthorized');
    }
});

Composable Auth Provider Configuration ​

Build a robust authentication mechanism with a composable authentication provider configuration, allowing seamless switching between environments (e.g., testing and production).

typescript
import { MemoryAuthProvider, JwtAuthProvider } from 'blendsdk/webafx-auth';

const environment = process.env.NODE_ENV || 'production';

const provider = environment === 'test'
    ? new MemoryAuthProvider({
        validTokens: {
            'test-token': {
                sub: 'test-user',
                claims: {},
                token: 'test-token',
            },
        },
    })
    : new JwtAuthProvider({
        secret: 'my-secret-key',
        algorithms: ['HS256'],
    });

// Express app setup to use the provider
const app = express();
app.use(async (req, res, next) => {
    let authResult;
    try {
        const token = req.headers['authorization']?.split(' ')[1];
        authResult = token ? await provider.validate(token) : undefined;
    } catch (error) {
        console.error('Authentication Error:', error.message);
        return res.status(401).json({ error: 'Unauthorized' });
    }
    if (!authResult) return res.status(401).send('Unauthorized');
    req.user = authResult;
    next();
});
