Introduction ​

In this guide, you'll learn how to build robust command-line tools using the BlendSDK's cmdline package. We'll start with setting up a simple CLI to parse arguments, define commands and options, and generate auto-help outputs. By the end of this tutorial, you'll have a solid understanding of how to structure CLI applications using subcommands and error handling patterns effectively.

Prerequisites ​

Before you start, ensure you have the following:

  • Node.js installed on your system
  • Basic knowledge of TypeScript
  • Familiarity with command-line interfaces
  • Terminal or command prompt access

Setting Up CLI Argument Parser ​

We'll start by creating a basic command-line parser.

typescript
import { CommandLineParser } from 'blendsdk/cmdline';

const parser = new CommandLineParser({ name: 'example-cli' });

parser.addCommand({
  name: 'greet',
  options: [
    {
      name: 'name',
      type: 'string',
      required: true,
      description: 'Name of the person to greet',
    },
  ],
  handler: async (options) => {
    console.log(`Hello, ${options.name}!`);
  },
});

await parser.execute();

This setup creates a basic CLI tool with a greet command that requires a name option.

Command and Option Definitions ​

Next, let's expand our CLI with additional commands and options.

typescript
import { CommandLineParser, ICommand } from 'blendsdk/cmdline';

const parser = new CommandLineParser({ name: 'utility-cli' });

const echoCommand: ICommand = {
  name: 'echo',
  description: 'Echo the provided message',
  options: [
    {
      name: 'message',
      type: 'string',
      required: true,
      description: 'Message to be echoed',
    },
  ],
  handler: async (options) => {
    console.log(options.message);
  },
};

parser.addCommand(echoCommand);

await parser.execute();

By adding the echo command, you allow users to print a provided message to the console.

Type-Safe Argument Parsing ​

BlendSDK ensures type-safe handling of arguments. You can define custom validators to enforce rules on argument types.

typescript
import { CommandLineParser, ICommand } from 'blendsdk/cmdline';

const isNonEmptyString = (value: string) => value.trim() !== '' || 'String cannot be empty';

const parser = new CommandLineParser({ name: 'type-safe-cli' });

parser.addCommand({
  name: 'reverse',
  options: [
    {
      name: 'text',
      type: 'string',
      required: true,
      validator: isNonEmptyString,
      description: 'Text to reverse',
    },
  ],
  handler: async (options) => {
    const reversedText = options.text.split('').reverse().join('');
    console.log(reversedText);
  },
});

await parser.execute();

This command validates that the text option is a non-empty string before processing.

Auto-Generated Help Output ​

BlendSDK automatically generates help messages based on the defined commands and options.

typescript
import { CommandLineParser } from 'blendsdk/cmdline';

const parser = new CommandLineParser({ name: 'auto-help-cli' });

parser.addCommand({
  name: 'info',
  description: 'Displays information about the CLI tool',
  options: [
    {
      name: 'help',
      type: 'boolean',
      description: 'Show help message',
    },
  ],
  handler: async (options) => {
    if (options.help) {
      parser.help();
    } else {
      console.log('Auto Help CLI Tool.');
    }
  },
});

await parser.execute();

You can explicitly call parser.help() to display help output, but users can access it using a --help option as well.

Subcommand Patterns ​

Subcommands are an excellent way to structure complex CLI tools.

typescript
import { CommandLineParser, ICommand } from 'blendsdk/cmdline';

const parser = new CommandLineParser({ name: 'project-cli' });

const buildCommand: ICommand = {
  name: 'build',
  description: 'Build the project',
  options: [
    {
      name: 'config',
      type: 'string',
      required: true,
      description: 'Configuration to use for building',
    },
  ],
  handler: async (options) => {
    console.log(`Building project using ${options.config} configuration.`);
  },
};

parser.addCommand(buildCommand);

await parser.execute();

In this pattern, subcommands like build help logically arrange functionalities, promoting organized command hierarchies.

Error Handling ​

It is crucial to implement error handling for a user-friendly CLI experience.

typescript
import { CommandLineParser, MissingRequiredOptionError } from 'blendsdk/cmdline';

const parser = new CommandLineParser({ name: 'error-handling-cli' });

parser.addCommand({
  name: 'send',
  options: [
    {
      name: 'message',
      type: 'string',
      required: true,
      description: 'Message to send',
    },
  ],
  handler: async (options) => {
    try {
      if (!options.message) {
        throw new Error('Message is required');
      }
      console.log(`Message sent: ${options.message}`);
    } catch (error) {
      if (error instanceof MissingRequiredOptionError) {
        console.error(`Error: ${error.message}`);
      } else {
        console.error('An unexpected error occurred:', error);
      }
    }
  },
});

await parser.execute();

This example handles errors, such as missing options, gracefully informing users of the issue.
