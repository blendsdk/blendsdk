Introduction ​

In this guide, you'll learn how to perform database operations using the BlendSDK with a focus on PostgreSQL. We'll cover type-safe SQL building, CRUD operations, connection pooling, transaction management, and parameterized queries to prevent SQL injection. By the end of this tutorial, you'll build a simple application that connects to a PostgreSQL database, performs CRUD operations, and handles transactions.

Prerequisites ​

Before starting, ensure you have the following:

  • Basic understanding of TypeScript and Node.js
  • PostgreSQL database installed and running
  • TypeScript 5.6.0 or higher installed
  • Access to a PostgreSQL database (you should have a database and user set up with appropriate permissions)
  • Node.js and npm/yarn installed for managing packages

Setting Up BlendSDK for Database Operations ​

First, you need to install the necessary packages for BlendSDK. If you haven't already, set up a new Node.js project and install the packages:

bash
npm init -y
npm install blendsdk pg yesql postgres-array

Step 1: Configuring PostgreSQL Connection ​

Create a PostgreSQL database configuration in a new file database.ts and establish a connection using the PostgreSQLDatabase class.

typescript
import { PostgreSQLDatabase } from 'blendsdk/postgresql';

const config = {
  host: 'localhost',
  port: 5432,
  database: 'mydb',
  user: 'myuser',
  pass: 'mypassword',
};

export const db = new PostgreSQLDatabase(config);

export async function connectToDatabase() {
  try {
    await db.connect();
    console.log('Connected to PostgreSQL database.');
  } catch (error) {
    console.error('Database connection failed:', error);
  }
}

Step 2: Implementing CRUD Operations ​

Let's define methods for each CRUD operation. We'll use BlendSDK's type-safe builders to ensure our SQL interactions are robust and secure.

Create a Record ​

Create an insertUser.ts file to add users to a database.

typescript
import { db } from './database';

export async function insertUser(name: string, email: string) {
  try {
    const user = await db
      .insert('users')
      .values({ name, email })
      .returning('*')
      .executeReturnSingle();

    console.log('Inserted User:', user);
  } catch (error) {
    console.error('Error inserting user:', error);
  } finally {
    await db.disconnect();
  }
}

Read a Record ​

To read records, use executeQuery to safely fetch user data.

typescript
import { db } from './database';

export async function fetchUsers() {
  try {
    const result = await db.executeQuery<{ id: number; name: string }>(
      'SELECT id, name FROM users'
    );
    console.log('Users:', result.records);
  } catch (error) {
    console.error('Error fetching users:', error);
  } finally {
    await db.disconnect();
  }
}

Update a Record ​

Here's how you can update a user's information.

typescript
import { db } from './database';

export async function updateUser(email: string, newName: string) {
  try {
    const updatedUser = await db
      .update('users')
      .values({ name: newName })
      .filter({ email })
      .returning('*')
      .executeReturnSingle();

    console.log('Updated User:', updatedUser);
  } catch (error) {
    console.error('Error updating user:', error);
  } finally {
    await db.disconnect();
  }
}

Delete a Record ​

Delete records accurately by defining a clear filter.

typescript
import { db } from './database';

export async function deleteUser(email: string) {
  try {
    const deletedUser = await db
      .delete('users')
      .filter({ email })
      .returning('*')
      .executeReturnSingle();

    console.log('Deleted User:', deletedUser);
  } catch (error) {
    console.error('Error deleting user:', error);
  } finally {
    await db.disconnect();
  }
}

Step 3: Managing Transactions ​

Transactions ensure a series of operations are atomic. Here's how to implement a transaction for creating a user and then updating their record.

typescript
import { db } from './database';

async function transactionExample() {
  try {
    const result = await db.withTransaction(async transactionDb => {
      const newUser = await transactionDb
        .insert('users')
        .values({ name: 'Charlie', email: 'charlie@example.com' })
        .returning('*')
        .executeReturnSingle();

      const updatedUser = await transactionDb
        .update('users')
        .values({ name: 'Charles' })
        .filter({ email: 'charlie@example.com' })
        .returning('*')
        .executeReturnSingle();

      return updatedUser;
    });

    console.log('Transaction Completed. Updated User:', result);
  } catch (error) {
    console.error('Transaction failed:', error);
  } finally {
    await db.disconnect();
  }
}

transactionExample();
