Welcome to the BlendSDK Guides section! Whether you are just beginning your journey or are an experienced developer looking to delve into advanced topics, our guides offer step-by-step instructions and best practices. Explore our curated paths to find the right starting point for your needs.

Featured: BlendScript ​

BlendScript Course ​

Learn BlendScript as a formula author, then integrate it into an external TypeScript application. The first part is written for people familiar with spreadsheet formulas; no programming knowledge is required.

  • Difficulty: Beginner to Intermediate

Getting Started Path ​

Standard Library ​

Discover zero-dependency utility functions, type guards, and string formatting with the BlendSDK standard library. Perfect as a foundational primer before diving into more complex projects.

  • Difficulty: Beginner

Building REST APIs ​

Learn to build a production-ready REST API using BlendSDK, equipped with structured logging and best practices to streamline your backend development.

  • Difficulty: Intermediate

Database Operations ​

Master type-safe SQL building and CRUD operations while integrating PostgreSQL into your BlendSDK applications for powerful data management.

  • Difficulty: Intermediate

PostgreSQL Database Migrations ​

Change a DatabaseSchema once, generate reviewable SQL from the committed snapshot, and apply the same immutable history in every environment.

  • Difficulty: Intermediate

Full-Stack Path ​

Building REST APIs ​

Build robust REST APIs that serve as the backbone of your full-stack applications. This guide focuses on scalability and seamless integration.

  • Difficulty: Intermediate

Database Operations ​

Enhance your full-stack projects with efficient database interaction through BlendSDK's tools for smooth CRUD operations and seamless PostgreSQL integration.

  • Difficulty: Intermediate

Caching & Pub/Sub ​

Implement caching and pub/sub patterns using Redis and in-memory strategies, optimized for performance and reliability in BlendSDK applications.

  • Difficulty: Intermediate

Authentication ​

Ensure secure user authentication using JWT, OAuth2, and OIDC discovery, while managing multi-tenant environments with BlendSDK's robust security features.

  • Difficulty: Intermediate

Sending Email ​

Integrate domain-specific SMTP email capabilities including template support and comprehensive testing patterns with BlendSDK's seamless email solutions.

  • Difficulty: Intermediate

Internationalization ​

Build global-ready applications with multi-language support through translation catalogs, locale resolution, and custom sources integration.

  • Difficulty: Intermediate

Advanced/Tooling Path ​

Code Generation ​

Efficiently generate TypeScript types, Zod schemas, and OpenAPI specs from your database schema to streamline your development workflow.

  • Difficulty: Advanced

Production Migration Runbook ​

Deploy committed PostgreSQL migrations through one guarded job with preflight, verification, and forward-recovery procedures.

  • Difficulty: Advanced

Structured Logging ​

Employ production-ready structured logging using Pino, designed for deep integration with BlendSDK web applications for superior logging capabilities.

  • Difficulty: Advanced

React Integration ​

Leverage BlendSDK's React utilities like custom hooks for authentication, i18n, and APIs to build cohesive full-stack applications.

  • Difficulty: Advanced

CLI Tools ​

Develop sophisticated command-line tools with BlendSDK's features for argument parsing and dynamic help generation.

  • Difficulty: Advanced

Suggested Learning Order ​

For those new to the BlendSDK, we recommend starting with:

  1. BlendScript Course for formula-based business rules
  2. Standard Library for general TypeScript utilities
  3. Building REST APIs for server applications
  4. Database Operations for data access

For further learning, follow the paths designed above that align with your skill level and project needs.
