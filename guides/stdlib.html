Introduction ​

In this guide, we'll explore the powerful utilities provided by the BlendSDK standard library, blendsdk/stdlib. This package includes type guard functions, string formatting capabilities, and general utility functions. You'll learn how these can help you write cleaner, more efficient TypeScript code, forming a foundation for other BlendSDK offerings.

By the end of this guide, you will understand how to:

  • Use type guard functions to validate data types effectively.
  • Format strings dynamically with placeholder templates.
  • Utilize utility functions for common operations.
  • Appreciate the zero-dependency design philosophy that ensures wide compatibility and concise implementations.

Prerequisites ​

To follow this guide, you should have:

  • Basic knowledge of TypeScript and familiarity with types and interfaces.
  • A TypeScript-friendly environment set up.
  • Node.js and npm/yarn installed to install the blendsdk umbrella package.

Getting Started ​

Installation ​

To begin, install the blendsdk umbrella package via npm or yarn:

bash
npm install blendsdk

or

bash
yarn add blendsdk

Basic Setup ​

Here’s a minimal setup to start using the blendsdk/stdlib package:

typescript
import { formatString } from 'blendsdk/stdlib';

async function exampleUsage() {
    const result = formatString("Hello ${name|Guest}", { name: "Alice" });
    console.log(result); // Output: "Hello Alice"
}

exampleUsage();

Type Guard Functions ​

Type guard functions in blendsdk/stdlib help validate and work with different data types effectively.

isString ​

The isString function checks if a given value is a string primitive. This avoids improper usage of non-string values.

typescript
import { isString } from 'blendsdk/stdlib';

async function exampleUsage() {
    const values = ['test', 123, true, null];
    values.forEach(value => {
        if (isString(value)) {
            console.log(`${value} is a string.`);
        } else {
            console.log(`${value} is not a string.`);
        }
    });
}

exampleUsage();

isNumber and isBoolean ​

Use similar guards like isNumber and isBoolean to validate numeric and boolean data types, ensuring robust type safety.

typescript
import { isNumeric, isBoolean } from 'blendsdk/stdlib';

async function exampleUsage() {
    const testValues = [42, '42', true, false, {}];
    testValues.forEach(value => {
        if (isNumeric(value)) {
            console.log(`${value} is numeric.`);
        } else if (isBoolean(value)) {
            console.log(`${value} is a boolean.`);
        } else {
            console.log(`${value} is neither numeric nor boolean.`);
        }
    });
}

exampleUsage();

String Formatting with Template Placeholders ​

The formatString function allows defining strings with placeholders using the ${...} syntax. You can then replace these placeholders with values from an object.

Basic String Replacement ​

typescript
import { formatString } from 'blendsdk/stdlib';

async function exampleUsage() {
    const result = formatString("Hello ${name}", { name: "John" });
    console.log(result); // Output: "Hello John"
}

exampleUsage();

Nested Object Properties ​

Access nested values within an object using dot notation.

typescript
import { formatString } from 'blendsdk/stdlib';

async function exampleUsage() {
    const user = { details: { name: "Alice", city: "Amsterdam" } };
    const result = formatString("${details.name} lives in ${details.city}", user);
    console.log(result); // Output: "Alice lives in Amsterdam"
}

exampleUsage();

Handling Defaults ​

Specify default values if a placeholder key is missing or undefined.

typescript
import { formatString } from 'blendsdk/stdlib';

async function exampleUsage() {
    const result = formatString("Hello ${user|Guest}");
    console.log(result); // Output: "Hello Guest"
}

exampleUsage();

Utility Functions ​

Utility functions in blendsdk/stdlib make data handling simpler and more concise.

wrapInArray ​

wrapInArray ensures a value is always handled as an array, which is useful for functions expecting iterable inputs.

typescript
import { wrapInArray } from 'blendsdk/stdlib';

async function exampleUsage() {
    const values = [42, 'test', null];
    values.forEach(value => {
        const array = wrapInArray(value);
        console.log(array); // Converts values to arrays, [42], ['test'], []
    });
}

exampleUsage();

Handling Null or Undefined ​

The isNullOrUndef function helps safely handle potentially uninitialized values by checking for null or undefined.

typescript
import { isNullOrUndef } from 'blendsdk/stdlib';

async function exampleUsage() {
    const values = [null, undefined, 0, 'hello'];
    values.forEach(value => {
        if (isNullOrUndef(value)) {
            console.log(`${value} is null or undefined.`);
        } else {
            console.log(`${value} is defined.`);
        }
    });
}

exampleUsage();

Zero-Dependency Design Philosophy ​

The blendsdk/stdlib package is crafted with a zero-dependency philosophy, meaning it operates independently without relying on third-party libraries. This design promises:

  • Simplified maintenance and updates.
  • Reduced risk of external vulnerabilities.
  • Lower installation overhead, which enhances performance and reduces package size.
