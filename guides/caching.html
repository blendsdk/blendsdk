Introduction ​

In this guide, you'll learn how to implement caching and pub/sub mechanisms in your TypeScript applications using the BlendSDK. We'll explore how to set up CacheProvider with both in-memory and Redis backends and utilize PubSubProvider for effective message communication between services. By the end of this tutorial, you'll have a working solution for storing data efficiently and facilitating real-time communications using pub/sub messaging.

Prerequisites ​

Before you begin, ensure you have the following:

  • Installed Node.js (v14 or higher)
  • Installed npm or yarn
  • A running instance of Redis for testing (or use Docker as explained below)
  • Basic understanding of TypeScript
  • BlendSDK package installed:
    bash
    npm install blendsdk/webafx-cache

Setting Up Your Development Environment ​

In-Memory Cache Setup ​

Start by creating a simple project and installing the necessary BlendSDK packages. Here's how to set up a basic in-memory cache using MemoryCacheProvider.

typescript
import { MemoryCacheProvider } from 'blendsdk/webafx-cache';

// Initialize the Memory Cache Provider
const memoryCache = new MemoryCacheProvider({
    rootKey: 'MyApp',
    cleanupIntervalMs: 60000, // Automatically clean up expired entries every minute
});

// Example: Set and get data with a TTL of 300 seconds
async function cacheExample() {
    await memoryCache.set('session:123', { user: 'Alice' }, 300);
    const session = await memoryCache.get<{ user: string }>('session:123');
    console.log(session?.user); // Output: Alice
}

cacheExample();

Redis Cache Setup ​

For a persistent and distributed option, configure the RedisCacheProvider.

typescript
import { RedisCacheProvider } from 'blendsdk/webafx-cache';

// Configure the Redis Cache Provider
const redisCache = new RedisCacheProvider({
    rootKey: 'MyApp',
    host: 'localhost',
    port: 6379,
});

// Example: Set and get data
async function redisCacheExample() {
    await redisCache.set('product:1', { name: 'Smartphone' }, 600);
    const product = await redisCache.get<{ name: string }>('product:1');
    console.log(product?.name); // Output: Smartphone
}

redisCacheExample();

Docker Redis Setup ​

To run Redis using Docker for development/testing:

bash
docker run --name redis-dev -p 6379:6379 -d redis

Core Cache Operations ​

Once you've set up a cache provider, you can perform various operations:

Setting and Getting Values ​

typescript
await memoryCache.set('item:101', { description: 'A cached item' }, 120);
const item = await memoryCache.get<{ description: string }>('item:101');
console.log(item?.description); // Output: A cached item

Deleting and Checking Existence ​

typescript
await memoryCache.delete('item:101');
const exists = await memoryCache.exists('item:101');
console.log(exists); // Output: false

Updating TTL and Clearing Cache ​

typescript
await memoryCache.expire('item:101', 300); // Extend TTL to 300 seconds
await memoryCache.clear(); // Clears all cached entries

Pub/Sub Messaging ​

Set up and utilize pub/sub messaging to create real-time communication channels.

Redis Pub/Sub Configuration ​

typescript
import { RedisPubSubProvider } from 'blendsdk/webafx-cache';

// Initialize the Redis Pub/Sub Provider
const redisPubSub = new RedisPubSubProvider({
    channelPrefix: 'MyApp',
    host: 'localhost',
    port: 6379,
});

// Example: Subscribe and publish messages
async function pubSubExample() {
    await redisPubSub.subscribe('notifications', (msg) => {
        console.log('Received notification:', msg.data);
    });

    await redisPubSub.publish('notifications', { message: 'Hello World!' });
}

pubSubExample();

Implementing WebAFX Plugin ​

Integrate the cache and pub/sub providers with WebAFX for harmonized application management.

typescript
import { createApp } from 'blendsdk/webafx';
import { createCachePlugin, createPubSubPlugin } from 'blendsdk/webafx-cache';

const app = createApp();
app.use(createCachePlugin(redisCache));
app.use(createPubSubPlugin(redisPubSub));

// Define your application logic here

Real-World Usage ​

Employ advanced caching patterns like cache-aside, write-through, and real-time state synchronization to enhance application performance and scalability across microservices or collaborative environments.

typescript
async function cacheAsidePattern(userId: string) {
    const user = await redisCache.get<{ name: string }>(`user:${userId}`) ?? await fetchUserFromDb(userId);
    if (!user) {
        await redisCache.set(`user:${userId}`, user, 300);
    }
    return user;
}

async function fetchUserFromDb(userId: string) {
    // Simulate database fetch
    return { name: 'John Doe' };
}
