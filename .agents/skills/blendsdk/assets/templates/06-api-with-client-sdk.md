# Template: API with Client SDK

> **Complexity**: Intermediate
> **Packages Used**: webafx, codegen, api-client
> **Docker**: None
> **Features**: OpenAPI contract, typed generated client, paginated response, drift check in CI

## Overview

A WebAFX API plus a typed TypeScript client generated from the same controllers. One `blendsdk.api.ts` file names the controllers. `blendsdk api generate` writes a committed `api.json` contract and a `src/api-client/` directory. `blendsdk api check` fails the build when either artifact drifts, so the server and its clients cannot disagree.

## Prerequisites

- Node.js >= 22.0.0
- Yarn or npm

## File: blendsdk.api.ts

```typescript
import { defineApiContract } from 'blendsdk/codegen';
import { GreetingsController } from './src/controllers/greetings-controller.js';

export default defineApiContract({
  outputDir: 'src/api-client',
  contractFile: 'api.json',
  controllers: [{ basePath: '/api/greetings', controller: GreetingsController }],
  openapi: {
    title: '{{PROJECT_NAME}} API',
    version: '1.0.0',
    description: 'Greetings API with a generated typed client.',
    servers: [{ url: 'http://localhost:3000', description: 'Local development server' }],
    securitySchemes: {
      bearerAuth: {
        type: 'http',
        scheme: 'bearer',
        bearerFormat: 'JWT',
        description: 'JWT obtained from the login endpoint.',
      },
    },
    defaultSecurity: [{ bearerAuth: [] }],
  },
  generator: { runtimeImport: 'blendsdk/api-client' },
});
```

Add one `{ basePath, controller }` entry for every controller you want in the contract. `outputDir` and `contractFile` are resolved relative to this file.

## File: src/controllers/greetings-controller.ts

```typescript
import { BaseController, NotFoundError } from 'blendsdk/webafx';
import { Request, Response } from 'express';
import { z } from 'zod';

/** One greeting returned by the API. */
const greetingSchema = z.object({
  id: z.number(),
  message: z.string(),
});

/** Query parameters accepted by the paginated list route. */
const listQuerySchema = z.object({
  page: z.coerce.number().int().min(1).default(1),
  limit: z.coerce.number().int().min(1).max(100).default(20),
});

/** Input accepted by the create route. */
const createGreetingSchema = z.object({
  message: z.string().min(1).max(200),
});

/** Shape of a standard error body. */
const errorSchema = z.object({
  success: z.boolean(),
  error: z.object({ message: z.string(), statusCode: z.number() }),
});

export class GreetingsController extends BaseController {
  routes() {
    return [
      this.route()
        .get('/')
        .openapi({
          summary: 'List greetings',
          tags: ['greetings'],
          operationId: 'listGreetings',
          envelope: 'body', // keep the pagination object
          responses: [
            { statusCode: 200, description: 'One greeting', schema: greetingSchema },
          ],
        })
        .validate(listQuerySchema)
        .handle(this.listGreetings),

      this.route()
        .get('/:id')
        .openapi({
          summary: 'Get a greeting',
          tags: ['greetings'],
          operationId: 'getGreeting',
          pathParams: {
            id: { schema: z.coerce.number().int().min(1), description: 'Greeting ID' },
          },
          responses: [
            { statusCode: 200, description: 'Greeting details', schema: greetingSchema },
            { statusCode: 404, description: 'Greeting not found', schema: errorSchema },
          ],
        })
        .handle(this.getGreeting),

      this.authenticated()
        .post('/')
        .openapi({
          summary: 'Create a greeting',
          tags: ['greetings'],
          operationId: 'createGreeting',
          responses: [
            { statusCode: 201, description: 'Greeting created', schema: greetingSchema },
            { statusCode: 400, description: 'Validation error', schema: errorSchema },
            { statusCode: 401, description: 'Authentication required', schema: errorSchema },
          ],
        })
        .validate(createGreetingSchema)
        .handle(this.createGreeting),
    ];
  }

  async listGreetings(req: Request, res: Response) {
    const { page, limit } = req.services.getParams<{ page: number; limit: number }>();
    const greetings = await listFromStore();
    const start = (page - 1) * limit;
    const items = greetings.slice(start, start + limit);
    this.paginated(res, items, greetings.length, page, limit);
  }

  async getGreeting(req: Request, res: Response) {
    const { id } = req.services.getParams<{ id: number }>();
    const greeting = await findGreeting(id);
    if (!greeting) {
      throw new NotFoundError(`Greeting ${id} not found`);
    }
    this.ok(res, greeting);
  }

  async createGreeting(req: Request, res: Response) {
    const { message } = req.services.getParams<{ message: string }>();
    const created = await saveGreeting(message);
    this.created(res, created);
  }
}
```

The response schema for a `'body'` route describes one item. The generated client wraps it as `PaginatedResponse<T>`.

## File: src/consumer/greetings-client.ts

This is the hand-written module that uses the generated client. Keeping it in compiled source means `yarn build` fails if the generated client ever stops type-checking.

```typescript
import { BearerAuth } from 'blendsdk/api-client';
import { createAppClient, type AppClient } from '../api-client/index.js';
import type {
  GreetingsGetGreetingResult,
  GreetingsListGreetingsResult,
} from '../api-client/types.js';

/** Creates the typed client for a base URL. */
export function createGreetingsClient(baseUrl: string): AppClient {
  return createAppClient({ baseUrl });
}

/** Creates the client with bearer-token authentication. */
export function createAuthenticatedClient(
  baseUrl: string,
  getToken: () => string | Promise<string>
): AppClient {
  return createAppClient({ baseUrl, auth: new BearerAuth({ getToken }) });
}

/** Fetches one greeting by id. */
export async function fetchGreeting(
  client: AppClient,
  id: number
): Promise<GreetingsGetGreetingResult> {
  return client.greetings.getGreeting({ id });
}

/** Fetches one page of greetings, including the pagination metadata. */
export async function listGreetings(
  client: AppClient,
  page = 1,
  limit = 20
): Promise<GreetingsListGreetingsResult> {
  return client.greetings.listGreetings({ page, limit });
}
```

The paginated result is `PaginatedResponse<T>`: read items from `page.data` and totals from `page.pagination`.

```bash
yarn dev

# Verify the committed artifacts match the controllers
yarn check:api
```

## CI Integration

Run `check:api` after `build`, so type errors are caught first and drift is caught second.

```yaml
# .github/workflows/ci.yml
jobs:
  verify:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 22
      - run: yarn install --frozen-lockfile
      - run: yarn build
      - run: yarn check:api
```

`check:api` exits `1` when `api.json` or any generated client file differs from what the controllers produce today.

## Next Steps

1. **Re-run `yarn generate:api` after every route or `.openapi()` change** and commit `api.json` together with `src/api-client/`.
2. **Add a controller** by writing its `.openapi()` metadata, registering it in `src/index.ts`, and adding a `{ basePath, controller }` entry to `blendsdk.api.ts`.
3. **Add authentication on the client** with `BearerAuth`, `ApiKeyAuth`, or `CookieSessionAuth`, then read `page.pagination` where you need totals.
4. **Keep `check:api` in CI** so a route change that was never regenerated fails the build instead of reaching a consumer.
