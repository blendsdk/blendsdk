# Getting Started

> Guides for installing, scaffolding, and deploying BlendSDK applications.

## Guides

| # | Guide | Description |
|---|-------|-------------|
| 1 | [Installation](installation.md) | Install `blendsdk`, peer dependencies, and TypeScript configuration |
| 2 | [Project Scaffolding](project-scaffolding.md) | Create a new project from scratch with recommended structure |
| 3 | [Docker Setup](docker-setup.md) | Set up Docker services for PostgreSQL, Redis, and Mailpit |
| 4 | [Production Deployment](production-deployment.md) | Build, optimize, and deploy to production |

## Prerequisites

- **Node.js** >= 22.0.0
- **TypeScript** >= 5.6.0
- **Package manager**: npm, yarn, or pnpm
- **Docker** (optional, for database/cache/mail integration tests)
