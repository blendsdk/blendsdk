# blendscript Overview

---

## What It Is

`blendsdk/blendscript` is a small, safe expression language designed for defining business rules in a readable and structured format. It allows applications to dynamically validate and evaluate expressions based on user-defined schemas.

---

## Key Features

- **Readable Syntax**: Offers a syntax familiar to users of spreadsheet formulas, making it easier to define expressions.
- **Strong Validation**: Validates expressions against pre-defined schemas before evaluation.
- **Safety**: Operates without using `eval`, `Function`, dynamic imports, or any I/O operations, ensuring a secure environment.
- **Opaque Compiled Expressions**: Compiles expressions into opaque handles for subsequent evaluations without exposing internals.

## When To Use

Consider using `blendsdk/blendscript` in scenarios such as:
- Implementing business rules in applications where dynamic expression evaluation is needed.
- Creating logic that requires validation of user inputs against defined schemas.
- Enforcing type safety and validation in configuration or rule expressions without exposing host capabilities.

## Architecture

The architecture of `blendsdk/blendscript` is built around a deterministic expression evaluation model. It utilizes the following key design patterns:
- **Parser**: Tokenizes the input expression to validate syntax and construct an abstract syntax tree (AST).
- **Analyzer**: Validates the AST against the provided schema, ensuring all fields are correctly defined and types are compatible.
- **Evaluator**: Executes the compiled expression against the actual runtime data, returning results and diagnostics as required.

Key components work together to ensure an isolated execution context free from host influences.

## Minimum Example

Here is the shortest complete working example demonstrating core functionality:

```typescript
import { compileExpression, evaluateExpression } from 'blendsdk/blendscript';

const options = {
  schema: { enabled: { type: 'boolean' } },
};

const compilation = compileExpression('enabled == true', options);
if (compilation.ok) {
```
