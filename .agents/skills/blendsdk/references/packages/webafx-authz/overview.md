# webafx-authz Overview

---

## What It Is

The `blendsdk/webafx-authz` package provides route authorization helpers and claim translation functionalities specifically designed for use within WebAFX applications. By connecting provider-agnostic authorization logic to the WebAFX framework, it facilitates a seamless integration of security checks directly into route handlers.

---

## Key Features

- **Authorization Helpers**: Provides functions like `requireAccess` and `requireScopes` to enforce role and permission-based access control.
- **Token Decoding**: Decodes JWT tokens and extracts claims without verification for further processing.
- **Claims Translator Plugin**: Allows the registration of custom claims translators for flexible claims handling within the request lifecycle.
- **Principal Selection Flexibility**: Supports custom strategies for resolving access roles and permissions based on application-specific principal structures.
- **Integration with WebAFX**: Designed to be seamlessly integrated into the WebAFX framework, promoting a cohesive development experience.

---

## When To Use

- When you need to implement role- and permission-based access controls in your WebAFX applications.
- For applications that require handling JWT tokens and need to decode their claims without verification.
- If your application architecture involves a central claims translation mechanism to manage user permissions effectively.

## Architecture

The `blendsdk/webafx-authz` package employs a clean architecture pattern that separates concerns regarding authorization and translation of user claims. Key design patterns used include:

- **Plugin Pattern**: The `createClaimsTranslatorPlugin` function allows the registration of claims translators as singleton services, making it easy to manage claims across various routes.
- **Middleware Pattern**: The package utilizes WebAFX's middleware architecture to provide authorization checks directly in the routing logic, ensuring that requests are validated before reaching the final handlers.

## Minimum Example

The following example demonstrates the basic usage of the `blendsdk/webafx-authz` package for securing a route based on user permissions:

```typescript
import {
    requireAccess,
    createClaimsTranslatorPlugin,
} from 'blendsdk/webafx-authz';
import { WebApplication } from 'blendsdk/webafx';
import type { ClaimsTranslator } from 'blendsdk/authz';

const translator: ClaimsTranslator = {
    translate: () => ({ roles: [], permissions: [] }),
};

const app = new WebApplication();

app.use(createClaimsTranslatorPlugin(translator));

app.route()
    .get("/invoices")
    .secure()
    .authorize(requireAccess({ permissions: ["invoice:read"] }))
    .handle((req, res) => {
        res.send("Here are your invoices.");
    });
```
