# authz Overview

---

## What It Is

`blendsdk/authz` is a provider-agnostic TypeScript library that offers a set of primitives for handling authorization concepts. It provides functionalities for defining roles and permissions, translating claims into canonical grants, and evaluating access requirements against a principal.

---

## Key Features

- **Provider-Agnostic**: Works with various identity providers without being tied to specific implementations.
- **Claim Translation**: Translates provider-specific claims into standardized roles and permissions.
- **Access Evaluation**: Efficiently evaluates if a principal satisfies specified access requirements based on roles and permissions.
- **Type Safety**: Built entirely in TypeScript for type safety and developer productivity.
- **Runtime and Browser Compatibility**: Can be utilized in both server-side and client-side environments.

---

## When To Use

- When building applications that require flexible authorization mechanisms.
- When integrating with multiple identity providers and needing a uniform authorization vocabulary.
- For applications that need to perform custom claim translations and permission evaluations.
- When type safety is crucial, ensuring that roles and permissions are handled correctly at compile time.

## Architecture

The architecture of `blendsdk/authz` leverages several design patterns to enhance its functionality and extensibility:

- **Translation Pattern**: The library allows the definition of claim profiles that translate provider-specific claims into application-friendly roles and permissions.
- **Evaluation Pattern**: Provides functions to evaluate if a principal satisfies certain requirements, utilizing pure functions that keep evaluation independent of how grants were obtained.
- **Guard Pattern**: Implements runtime guards to validate untrusted values for role and permission checks.

This modular architecture ensures that different components can easily be extended or replaced, facilitating integration into diverse applications.

## Minimum Example

The following example demonstrates the core functionality of `blendsdk/authz`, including the creation of a claims translator and access evaluation.

```typescript
import {
    createClaimsTranslator,
    genericClaimsProfile,
    satisfiesAccess,
} from 'blendsdk/authz';

const ROLES = { Admin: 'admin' } as const;
const PERMISSIONS = { InvoiceRead: 'invoice:read' } as const;

const translator = createClaimsTranslator(
    genericClaimsProfile,
    { 'role:app-admin': { roles: [ROLES.Admin] } },
    {
        allowed: {
            roles: Object.values(ROLES),
            permissions: Object.values(PERMISSIONS),
        },
    }
);

const principal = translator.translate({
    userInfo: { roles: ['user'], permissions: ['invoice:read'] },
});

console.log(satisfiesAccess(principal, { permissions: [PERMISSIONS.InvoiceRead] })); // true
```
