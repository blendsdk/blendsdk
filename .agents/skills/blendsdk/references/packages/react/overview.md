# react Overview

---

## What It Is

`blendsdk/react` is a React component and hook library tailored for BlendSDK applications, enabling developers to leverage reusable components to streamline the development of user interfaces with seamless integration for global loading, internationalization, and authentication.

---

## Key Features

- 🔄 **GlobalLoader**: A customizable full-screen overlay with a CSS-only spinner to enhance UX during loading states.
- 🌍 **Internationalization (I18n)**: Support for loading translations asynchronously and switching locales dynamically.
- 🔒 **Authentication Components**: Built-in authentication context with hooks for managing user sessions and permissions.
- ⚡ **Type-safe API**: Full TypeScript support provides accurate types for components and hooks.
- 🛠️ **Flexible Configuration**: All configurable components come with sensible defaults, ensuring quick startup without extensive setup.
- 🚀 **Zero Dependencies**: It only requires React as a peer dependency, making it lightweight and easy to integrate.

---

## When To Use

Use `blendsdk/react` when developing BlendSDK applications that require:

- Robust loading indicators that must be managed from anywhere in the component tree.
- Dynamic translation capabilities for international users.
- A consistent approach to authentication and authorization within the application context.
- A developer-friendly experience with TypeScript support, ensuring type safety and reducing runtime errors.

---

## Architecture

`blendsdk/react` is designed around a context-based architecture, leveraging React's Context API for state management across components. Key design patterns include:

- **Provider-Consumer Pattern**: Uses context providers to manage global states such as loading and authentication.
- **Hooks**: Custom hooks like `useGlobalLoader`, `useTranslations`, and `useAuth` facilitate access to context values while maintaining type safety.

## Minimum Example

```typescript
import { GlobalLoaderProvider, useGlobalLoader } from 'blendsdk/react';

function App() {
  return (
    <GlobalLoaderProvider>
      <MyComponent />
    </GlobalLoaderProvider>
  );
}

function MyComponent() {
  const { showLoader, setText } = useGlobalLoader();

  const handleLoadData = async () => {
    setText("Loading...");
    showLoader(true);
    await fetchData();
    showLoader(false);
  };

  return <button onClick={handleLoadData}>Load Data</button>;
}
```
