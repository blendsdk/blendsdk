Why BlendSDK? ​

BlendSDK is your go-to solution for building complex, scalable applications with ease. By offering comprehensive support across web frameworks, database interactions, caching, authentication, internationalization, code generation, and more, BlendSDK empowers developers to streamline their development process and focus on creating value.

Seamless Integration ​

From connecting to databases to rendering web interfaces, BlendSDK ensures seamless integration across all layers of your application stack. Its plugin-based architecture and modular design mean that you can customize and scale your application as your needs evolve.

Robust Type Safety ​

Leveraging TypeScript's full potential, BlendSDK offers robust type safety across all its packages, reducing errors and improving maintainability. Developers benefit from consistent APIs and structured error handling, resulting in a more efficient development workflow.

Quick Start Example ​

Here's how you can set up a simple HTTP server with BlendSDK's web framework:

typescript
import { WebApplication, BaseController } from 'blendsdk/webafx';
import { Request, Response } from 'express';

class WelcomeController extends BaseController {
  routes() {
    return [this.route().get('/').handle(this.welcome)];
  }

  async welcome(req: Request, res: Response) {
    this.ok(res, { message: 'Welcome to BlendSDK!' });
  }
}

const app = new WebApplication({ PORT: 3000 });
app.registerController('/api', WelcomeController);

app.start().then(() => console.log('Server running on http://localhost:3000'));
